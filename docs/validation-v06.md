# v0.6.0-beta.1 本地候选验证

2026-10-03。此文件对应本轮本地候选，不代表已发布版本。旧v0.5材料及正式工程保持不变，没有安装软件、连接硬件、安装Skill、推送或发布。当前入口见[支持矩阵](support.md)。

## 改动与当前证据

- 新增只读 `project_intake.py` 与三个入门路径。IOC、TouchGFX、XPR/BD观察不依赖厂商工具；34项测试在Windows及WSL Ubuntu上，普通Python与优化模式四组通过。
- 受控复现旧CubeMX汇总中残留RUNNING，局部修复状态、真实退出码和后验结果；37项适配器测试在普通及优化模式通过。新增apply超时参数，默认每子进程360秒。
- 实际统计C源码和实际原创Model，在Linux宿主编译及运行通过；错误均值、空Reset负例按指定业务条件失败。Windows原有Model编译器入口及新显式C++入口也已验证。没有用伪造SDK补齐环境。
- 新增CI调用已经源码复核，本轮未推送，**远端CI未运行**。本地主机执行不能称为GitHub Actions通过。
- 两份公开配置按提交和哈希读取，既取得稳定信息，也保留具体解析失败；见[公开工程观察](public-adaptation.md)。没有执行第三方脚本或把完整上游工程打包。
