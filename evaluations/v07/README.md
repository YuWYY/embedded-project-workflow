# v0.7 定向回归与既有工程接手

初始计划共10次独立执行：原六类案例使用新候选各一次；两个未见的真实F103/CMake工程任务使用冻结v0.6与v0.7各一次。不重跑无Skill组，不与历史不同环境/任务的次数混合计算效果。

正式运行前，使用相同CLI、模型请求及进程级配置，在本轮空目录实际写入、读回并原子保存结果。预检失败不启动批量执行。无需安装软件、改变系统或全局AI配置、连接硬件、推送或发布。

`cases.json`和`prepare.py`保留原六类输入。执行代理只取得当前案例的原始材料、请求和指定Skill子目录，不取得评分文件、其他组结果、开发聊天或预制实现。真实工程的上游源码和完整生成/构建产物留本地，不在此目录复制第三方完整工程。

任务A在已有裸机主循环和CustomScreen2中接入累计秒数与循环次数，100ms生成业务快照，保留导航、按键和render loop。任务B来自独立成功基线，再施加250ms与菜单名变更，检验新代理保留当前设计并完成必要验证。两个组的输入、工具版本、路径规则和终点一致。

评分分别记录实际行为、配置保护、证据诚实和最终说明完整性；保留原六类冻结终点作为可追溯回归，不把说明分差称为代码能力差异。实际业务源码宿主契约、目标Debug构建和界面/硬件运行分开；无硬件操作，不宣称板上功能通过。

保留所有失败、超时、中断和环境问题。记录真实差异、来源哈希、可观测工具调用/输出字节、耗时及宿主usage；工具输出字节不等于磁盘读取量，缓存token不等于费用。新修订只复测受影响项并另列，不覆盖原始结果。这些案例观察不构成统计效果证明。
