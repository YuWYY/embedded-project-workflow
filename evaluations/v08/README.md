# v0.8 规划图独立演练

`prepare.py` 生成六组原创工程摘录和两组原有路由回归输入。前六组分别覆盖裸机、RTOS、单域 FPGA、异步双域、板卡资料冲突、最新配置接续；后两组原文复用 v0.7 的小编辑与首次概览。

```text
python evaluations/v08/prepare.py --output <新的输入目录>
python evaluations/v08/prepare.py --output <新的单项目录> --case 03-fpga-single-domain
```

输出目录必须不存在。每组包含请求、原始材料、来源说明；清单记录输入 SHA-256。合成摘录用于图与工程事实核对，不是可下载固件、完整厂商工程或已板测设计。

执行时每组使用独立上下文，仅提供该组原始材料、当前候选 Skill 及工作范围。评分材料、其他执行结果和修复答案不交给执行者。前六项需要实际图稿；后两项关注不扩大请求。读写预检通过后才执行正式案例。

原始进程记录、局部失败和图面审查留在本地隔离证据中；公开的脱敏结论见[验证记录](../../docs/validation-v08.md)。进程退出成功、SVG 可解析、模板重建一致，均不能替代工程事实与实际可读性核查。
