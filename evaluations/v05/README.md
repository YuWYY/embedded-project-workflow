# v0.5 独立行为输入

`cases.json` 是原创合成需求与原始材料，不是厂商运行证据。包含板级依据、架构分工、配置接续、硬件交接、工具缺口、DMA分析、局部修改及四类既有行为回归。准备器只复制案例与显式Skill快照，不生成标准答案。

```powershell
python -B evaluations/v05/prepare.py --output $CaseDirectory
```

执行代理仅获得准备后的Skill与各案例请求和材料，不读取评分或历史结论。只允许在案例工作目录内处理原创输入；不运行厂商工具或硬件。另行记录代理是否使用新上下文、哪些案例共用同一执行上下文以及实际来源哈希。模型回答由复核者依据行为评分，准备成功不代表案例通过。

真人Vivado地址修改与原生工具结果独立记录，不能用这些合成案例替代。
