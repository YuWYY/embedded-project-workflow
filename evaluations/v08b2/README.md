# v0.8.0-beta.2 原始评估材料

本目录提供七组原创合成输入的可重建入口。材料是工程事实与源码摘录，**不是厂商生成树或完整可构建工程**。不附带解题图、评分答案或旧试验输出；准备成功也不表示执行代理通过。

```text
python evaluations/v08b2/prepare.py --output <新的输入目录>
python evaluations/v08b2/prepare.py --case 04-fpga-dual-domain --output <新的单案例目录>
```

输出目录必须尚不存在。每项包含 `REQUEST.md`、原始材料及 `INPUT-HASHES.json`；顶层清单记录案例身份和 SHA-256。准备只使用 Python 标准库，不启动工程脚本、厂商软件或网络服务。不同机器的路径、文件时间和 Python 运行时间不进入输入内容。

| ID | 原始材料范围 |
|---|---|
| 01-baremetal-plan | USART 循环 DMA 命令接收、主循环 SPI 读取、硬件 PWM 和中断发送 |
| 02-rtos-plan | 当前流处理结构、配置版本不同的历史副本、任务与通信接口 |
| 03-fpga-single-domain | 同域串行样本、并行统计与告警、定时发送及复位材料缺口 |
| 04-fpga-dual-domain | FWFT 接口的异步 FIFO、双域握手及单复位组件契约 |
| 05-revision-conflict | 当前控制代码、冲突板卡资料、未实现的告警与事件记录需求 |
| 06-small-change | 独立 C 文件的单个时间边界条件 |
| 07-first-look | 工程配置、CMake 声明和用户源码位置的只读概览 |

前五项请求实际配套图。第六项只授权其工作副本的 `APP/report_gate.c` 修改；第七项仅只读。所有原始输入应保留，代理在独立副本中执行。

执行者只得到对应案例、冻结的候选 Skill 和通用执行环境。不得把其他案例结果、私有评分表或旧修图答案放入其工作目录。正式评估按计划先运行 02、04、06，评审后再决定是否继续剩余项；失败与定向复测分别记录。

STM32/CMake 和 Clocking Wizard 的真实工程 A/B 接续使用单独准备的工程副本，**不由本脚本冒充原生工程**。其准备、实际生成/构建/仿真与接续结果另行记录。包内这里只收录原创材料及脱敏结果，不收录第三方完整工程或厂商生成树。
