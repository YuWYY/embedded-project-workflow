# v0.2 原创行为案例

本目录公开10个合成请求与最小工程材料，覆盖用户预设结构、范围内调整、真实约束冲突、分配语义、人工改配置、工具表达限制、部分生成、中断恢复、陌生工具及小修改。全部为原创缩减案例；其中C/C++片段不是厂商库或完整固件。

## 准备与执行

在仓库根目录执行：

```text
python -B evaluations/v02/prepare.py --output "<仓库外新的空目录>"
```

入口复制候选Skill和原始案例；可编辑案例从baseline创建work，绝不复制上次评估的修改结果。拒绝非空目录或写回仓库。它只准备材料，不调用模型、厂商工具或硬件。

向新的执行者提供输出目录中的Skill和某案例的`USER_REQUEST.md`、原始input或baseline/work。要求按请求完成；不要提供本目录`reviewer-rubric.md`、历史答复或预期修复。只允许编辑请求明确允许的work文件。需要真实编译器或文档访问时如实记录可用性，不能把合成脚本称为CubeMX或TouchGFX真实生成。

评估者可以分组执行，但应公开组内是否共享上下文。按实际文件变化、工具证据、约定保留和结论复核，不按固定措辞、关键词或答案长度评分。每次评估保留候选文件身份；技术审阅和模型行为评估分开记录。

## 范围

- `17`：预设任务中增加遥测，只读建议。
- `18`：授权范围内修改配置并运行自有派生脚本。
- `19`：新期限与现有计算预算冲突，只读方案。
- `20`：静态分配、C static、创建时机和旧适配器限制。
- `21`：用户改控件名后，修复用户层引用，保留生成基类。
- `22`：GUI不能表达的对象使用正式用户扩展。
- `23`：退出0但生成中断、旧构建仍在。
- `24`：最新配置与旧通过结果不一致的只读续接。
- `25`：Zephyr声明源和派生文件分析，不运行Zephyr构建。
- `26`：只修已定位格式问题。

历史01—16中含私有原始工程与记录，本目录不发布其完整输入；本轮[逐例结果摘要](results-20260928.json)与[验证说明](../../docs/validation.md)分别记录结果和限制。此处可复跑的10例不是整个历史基准的公开替代。

原创输入与准备脚本采用仓库MIT许可。测试材料中的对象数、参数、工具限制和现象只对该案例成立，不是Skill的通用默认值。
