# 首次使用的三组对照

6个案例 × 无本Skill / v0.5完整Skill / v0.6完整Skill × 2次独立上下文。每次使用相同原始材料、工具环境和终点；执行者只能取得 `cases.json` 中一个案例的文件与请求，以及该组的Skill快照。不得提供 reviewer-rubric.md、其他执行结果或开发聊天。

其中1、2是只读接手，3、4、5、6包含真实文件修改；只读分析不算厂商生成或构建。案例配置是原创裁剪材料，不是可直接下载到硬件的完整工程。SDK类型的接口片段仅用于说明生成边界，不冒充SDK。

评分优先看实际差异与输入哈希；机械结果之外，由独立复核者阅读请求、产物和最终答复。保留失败、超时和未完成。源码后续修改必须另外记录复测，不覆盖第一次结果。

执行固定使用宿主实际支持的同一模型和推理设置，记录CLI版本、参数、每次thread ID、工具调用、耗时和宿主提供的usage字段。缓存输入不是实际费用，不能据此换算成本。案例是小样本，不能据此宣传效率或故障率得到统计证明。

最终结果与环境限制见 [当前验证](../../docs/validation-v06.md)。
