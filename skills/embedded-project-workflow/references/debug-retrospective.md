# 调试、回归与复盘

分析先保留多种解释，实现围绕最小可运行功能链推进。本指南不是每次修改必须执行的测量清单。

## 明确目标与版本

确认当前源码/构建、实际加载版本、协议/UI、硬件实装、工作条件和最后成功行为。区分用户观察、程序实现、主机测试、目标构建/读回、板载记录及独立仪器；缺记录不等于历史上没有发生。

检查从请求到采样准备、状态转移、输出使能、控制更新、正常停止/完成的可达路径。配置全零验收位、互相等待的准备条件或永远达不到的许可应按软件问题处理，不能继续以“功能已开放”交付。

普通边界暂停、饱和、完成、STOP和真正故障可能需要不同恢复语义。某次正常条件不足不自动需要永久锁存，也不自动意味着可以继续输出；依据具体故障响应契约判断。

## 从首故障，而非全部报错开始

按时间重建最早事件和前置状态，解释后续ADC过期、断流或UI超时是否由第一次停止动作造成。保留必要原始样本、事件时间、输出状态和故障分支信息，不为让结果好看删去异常。

列出当前最有证据的候选原因、支持与反例。新测量须回答：它能区分哪些原因，需哪个信号/带宽/时刻，两个结果会怎样改变下一步。先利用已有源码与日志，不重复索要全部波形。

当数据缺少唯一确定根因的字段时，给出可执行的最小定位动作，不将“很可能”升级为“已证明”。旧助手解释及后续撤回记录应一起检查。

## 保留信号的物理意义

- 端口电流、输入直通负载电流、电感峰值和软件估计量不同；控制、限流与硬件关断各自说明使用的量。
- 低速网页平均值不能排除短峰值；单次原码异常也不能独自证明危险电流。先检查参考、差分、偏置、量程、相位及数据配对。
- PI追踪自身反馈不证明绝对准确；用电压变化、能量方向和功率一致性发现矛盾，但同一板载测量链派生出的多条曲线不是独立计量。
- 跨多个PWM周期的相位扫描只能在相应稳态假设下分析等效轮廓，不是任意单周期瞬态波形。

对合并遥测核对各列源报文、刷新时间和缓存方式；同一CSV行可能包含不同时间的数据。按会话/诊断窗口去重计数，区分重启；名为`raw`的列也可能已做平均。累计最大值不能按每次调用耗时使用。

展示成功平台时同时保留全程状态和失败区间。说明选窗、滤波和被省略短段；遥测模式切换次数不是实测开桥次数，反馈标准差不是电感纹波或独立计量误差。

## 算真正的实时期限

从源码与时钟推导采样帧、DMA半区事件、实际覆写、PWM锁存、保护响应和控制周期。计时要注明CPU周期/外设计数单位、包围范围及未覆盖的排队/中断尾部；启动、换向和故障分支不能只用稳态PI耗时替代。

`max > budget`证明违反这个预算，但不必然是直接故障原因。检查预算越界是计数、暂停还是锁存；沿缓冲生命周期分别考虑事件到达、IRQ排队、复制前后位置和完整处理。先复制后计算的ISR跨过下一事件，不自动证明已复制的数据损坏；平均CPU低于100%也不证明最坏路径满足期限。

涉及实时问题时，优先判断是工作量、调度、缓冲所有权还是判据问题，避免只抬统计阈值或屏蔽一致性检查。

## 修改、转向和报告

先保留已工作版本及对应证据。回归从增量比较开始；不要一次重写采样、控制、保护、UI和协议后失去定位依据。必要重构围绕明确的不可达或时序问题展开，不以最少改几行作为唯一标准。

器件硬限制、用户限值、模型估计和实验条件分别注明依据及适用范围。极小给定未必具有足够信噪比；实验值应与硬件、量化/偏置、纹波和任务约束同时相容。不得为了验证通过偷偷扩大用户限值，也不得把未经论证的临时值永久化。

连续迭代仍停在同一位置、且没有新增鉴别信息时，比较回退、改变实验、缩短关键路径或重新分配责任。停止无信息的补丁循环不等于停止整个项目。

只测试改变的关键行为及必要接口。主机替身能验证算术、状态、顺序与竞争处理，不能证明实机期限或模型参数正确。完整下载读回也不等于闭环通过。

交付先说明已知结果和证据，再说明变化、反例、未决问题及下一步。复盘比较同一阶段和实际版本，不把某一分支旧缺陷覆盖所有后来版本；同硬件不等于启动条件、保护范围和用户已有知识均相同。
