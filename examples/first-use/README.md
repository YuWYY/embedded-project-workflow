# 原创只读入门材料

这三个独立目录用于认识配置来源，不需要厂商工具。使用步骤见[第一次使用](../../docs/first-use.md)。

- `cubemx/FirstLook.ioc`：两个任务和一个队列。
- `touchgfx/FirstLook.touchgfx`：两个页面和一个清空交互声明。
- `vivado/FirstLook.xpr` 与 `design_1.bd`：工程引用与一个 GPIO 实例。

均为独立编写的最小配置片段，沿用本仓库 MIT。**不是完整、可生成或可上板的厂商工程**，不含 SDK、GUI 资源、生成代码、编译产物、厂商模板、私人日志或安装路径。对象名用于定位；示例数值、版本和器件不能推广为推荐配置。缺少用户实现是练习内容，不是工具已验证的功能。

检查只读取文件并输出到终端。请勿用示例创建脚本回灌自己的工程。
