# MPSoC current-design handoff contract

Copyright (c) 2026 YuWYY. SPDX-License-Identifier: MIT

This original offline case uses Vivado 2025.1, ZCU102 rev 1.0 with board
definition `xilinx.com:zcu102:part0:3.4`, and `xczu9eg-ffvb1156-2-e`.

| Element | Agreed design |
|---|---|
| PS master | Zynq UltraScale+ MPSoC `M_AXI_HPM0_FPD` |
| PL clock | Board-preset PL0, requested 100 MHz |
| Interconnect | One AMD SmartConnect |
| Peripheral | Exactly one AXI GPIO 2.0, fixed instance `axi_gpio_0` |
| Channel 1 | Two output bits: bit 0 enable, bit 1 clear, reset output value 0 |
| Channel 2 | 32 input bits from the counter |
| User logic | Module reference `counter32_0` of original `counter32.v` |
| Top wrapper | Vivado-managed `soc_handoff.gen/sources_1/bd/system/hdl/system_wrapper.v`, regenerated by `make_wrapper`; user RTL remains separately owned |
| Counter | Synchronous active-low reset; reset > clear > enable; default stopped; paused value retained; modulo 2^32 |
| Reset | PS reset through AMD Processor System Reset to AXI and user logic |
| Initial map | Base `0xA0000000`, range `0x00010000` (64 KiB) |
| Validation boundary | BD validation, output products, wrapper, top synthesis, XSA without bitstream, SDT, separate RTL simulation |

The installed board preset uses a 33.330 MHz PS reference. Vivado computes
PL0 as **99,990,005 Hz** for its requested 100 MHz setting. The module clock
metadata matches that native value; neither value is a measured board clock.

After preparation the **current saved BD is the hardware configuration source**.
`scripts/prepare.tcl` creates only a new initial baseline. Never source it into
an existing project or use it to restore addresses after a user edit.
`scripts/export.tcl` opens the current project, validates it, generates current
outputs and exports hardware. It contains no GPIO address assignment.

User GUI edits, AI implementation and source-derived address verification must
be recorded separately. No GUI edit, new-context continuation, processor build,
runtime MMIO, implementation, bitstream or board operation is implied by these
sources. Current results are reported separately, with source identities.
