# 既有工程功能接手案例

本轮使用两个原创工程宿主接入同一个[纯C统计模块](../common/rolling-stats/README.md)。每个工程先由准备代理建立可生成、可构建的基线，再交给独立代理实施业务目标；最终源码是交付结果，不作为首次接手时的预制答案。

- [CubeMX/FreeRTOS](cubemx/README.md)：在预设任务和队列内处理合成输入，核对对象、用户入口、编译引用及MAP。
- [TouchGFX](touchgfx/README.md)：接入统计页面，再由真人添加Reset按钮/交互，新代理实现清空逻辑并保留状态。

两个宿主分别使用独立统计实例，没有设备通信，不代表 MCU 数据已经传输到 GUI。完整生成树、厂商依赖、原始日志及真人编辑工程留在本地隔离目录；这里只交付原创输入、代码、重建入口和脱敏结果。

[ESP-IDF案例](../esp-idf/README.md)复用同一业务核，但本轮不安装SDK，不执行其配置解析、目标生成、编译或运行。当前完成层级以[候选验收记录](../../docs/validation-v04.md)为准。

本轮结果与源码身份见 [分层验证摘要](validation-20260930.json)。CubeMX完成实际生成/构建；TouchGFX完成真人结构编辑、新代理接续和用户报告的界面验证；ESP-IDF仍为资料及源码层。
